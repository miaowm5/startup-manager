卸载 StartupManager

将执行以下操作，且不可撤销：

  • 删除全部 0 个自启项，并注销它们对应的计划任务
  • 删除配置、生成的脚本、日志与运行状态文件
  • 本程序立即退出；exe 文件需要你手动删除

输入「卸载」以确认：

已卸载
